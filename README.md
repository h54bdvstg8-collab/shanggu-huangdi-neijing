# 上古黄帝内经（玄隐遗密）知识库

三申道人传本《玄隐遗密》结构化知识库，用于检索经文原文与白云讲堂讲录。

## 内容结构

```
├── SKILL.md              # 技能主文件（章节索引+核心框架+主题索引）
├── glossary.md           # 关键术语与定义
├── patterns.md           # 技法与模式（治法/针法/辨证/导引）
├── cheatsheet.md         # 速查表与决策规则
├── chapters/             # 全部章节原文
│   ├── ch01-ch14         # 完整古文原文（保留繁体原貌）
│   ├── ch15-ch16         # 白云讲堂讲录（口述，非原文）
│   └── ch17              # 脑髓神志原文+讲记合编
└── sources/              # 讲录原始底稿
```

## 说明

- **ch01-ch14** 为完整古文原文，底本为三申道人录《玄隐遗密》（中医古籍出版社）
- **ch15/ch16** 为白云讲堂口述讲录，非经文原文
- 本仓库仅供学术研究与个人学习使用

## 使用方式

在支持 Skill 的 AI 助手中加载本目录，即可按主题检索原文。
